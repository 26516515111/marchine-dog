## 数据层面改进

### 1. 数据增强

#### 1.1 Mosaic 增强

**作用**：将 4 张图片拼接成 1 张，增加背景多样性，提升小目标检测能力。

**配置方法**：
```yaml
# 文件: mycode/configs/ppyoloe_fire.yml
# 位置: TrainReader.sample_transforms

TrainReader:
  sample_transforms:
    - Decode: {}
    - Mosaic: {prob: 0.5}           # 新增，概率 50%
    - RandomDistort: {lower: 0.8, upper: 1.2, prob: 0.5}
    - RandomExpand: {fill_value: [123.675, 116.28, 103.53]}
    - RandomCrop: {}
    - RandomFlip: {prob: 0.5}
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `prob` | 执行 Mosaic 的概率 | 0.3-0.5 | 过高可能影响训练稳定性 |

#### 1.2 MixUp 增强

**作用**：将两张图片混合，增加样本多样性，提升泛化能力。

**配置方法**：
```yaml
TrainReader:
  sample_transforms:
    - Decode: {}
    - Mosaic: {prob: 0.5}
    - MixUp: {prob: 0.3}            # 新增，概率 30%
    - RandomDistort: {lower: 0.8, upper: 1.2, prob: 0.5}
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `prob` | 执行 MixUp 的概率 | 0.2-0.4 | 与 Mosaic 配合使用 |
| `alpha` | Beta 分布参数 | 1.5 | 控制混合比例 |

#### 1.3 CutMix 增强

**作用**：将一张图片的部分区域粘贴到另一张图片，增强局部特征学习。

**配置方法**：
```yaml
TrainReader:
  sample_transforms:
    - Decode: {}
    - CutMix: {prob: 0.3}
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `prob` | 执行 CutMix 的概率 | 0.2-0.4 | - |
| `alpha` | Beta 分布参数 | 1.0 | 控制裁剪区域大小 |

#### 1.4 颜色抖动增强

**配置方法**：
```yaml
TrainReader:
  sample_transforms:
    - RandomDistort:
        lower: 0.8          # 亮度下限
        upper: 1.2          # 亮度上限
        prob: 0.5           # 执行概率
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `lower` | 颜色变换下限 | 0.7-0.9 | 越小变换越强 |
| `upper` | 颜色变换上限 | 1.1-1.3 | 越大变换越强 |
| `prob` | 执行概率 | 0.3-0.5 | - |

### 2. 数据清洗

**方法**：
1. 检查标注文件，修正错误框
2. 去除噪声标注
3. 统一标注格式

**检查脚本**：
```python
import json

def check_annotations(ann_file):
    with open(ann_file, 'r') as f:
        data = json.load(f)
    
    errors = []
    for ann in data['annotations']:
        bbox = ann['bbox']
        # 检查边界框是否合法
        if bbox[2] <= 0 or bbox[3] <= 0:
            errors.append(f"Invalid bbox: {ann['id']}")
    
    return errors
```

## 训练策略改进

### 1. 训练轮数

**当前**：100 epochs

**改进**：300 epochs

**配置方法**：
```yaml
# 文件: mycode/configs/ppyoloe_fire.yml

epoch: 300                # 修改为 300

LearningRate:
  schedulers:
    - !CosineDecay
      max_epochs: 300     # 同步修改
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `epoch` | 训练轮数 | 100-300 | 数据少时需要更多轮数 |

### 2. 学习率配置

**当前**：0.001

**改进**：0.0005 或更小

**配置方法**：
```yaml
LearningRate:
  base_lr: 0.0005         # 修改为 0.0005
  schedulers:
    - !CosineDecay
      max_epochs: 300
    - !LinearWarmup
      start_factor: 0.0
      epochs: 10          # 增加预热轮数
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `base_lr` | 初始学习率 | 0.0001-0.001 | 越小训练越稳定 |
| `start_factor` | 预热起始因子 | 0.0 | 从 0 开始预热 |
| `epochs` | 预热轮数 | 5-10 | 防止初期震荡 |

### 3. 学习率调度策略

#### CosineDecay (余弦退火)

**作用**：学习率按余弦曲线衰减，有助于跳出局部最优

**配置方法**：
```yaml
schedulers:
  - !CosineDecay
    max_epochs: 300       # 总训练轮数
```

#### CosineAnnealingRestart (周期性余弦退火)

**作用**：周期性重启学习率，有助于探索更优解

**配置方法**：
```yaml
schedulers:
  - !CosineAnnealingRestart
    periods: [100, 100, 100]    # 每个周期的轮数
    restart_weights: [1, 0.5, 0.25]  # 每次重启的权重
```

#### StepDecay (阶梯衰减)

**配置方法**：
```yaml
schedulers:
  - !StepDecay
    milestones: [100, 200]      # 衰减节点
    gamma: 0.1                  # 衰减因子
```

### 5. EMA (指数移动平均)

**作用**：平滑模型参数，提升泛化能力

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `use_ema` | 是否使用 EMA | true | 推荐开启 |
| `ema_decay` | EMA 衰减率 | 0.999-0.9999 | 越大越平滑 |

### 6. 梯度裁剪

## 后处理优化

### 1. NMS 配置

**当前配置**：
```yaml
# 文件: PaddleDetection/configs/ppyoloe/_base_/ppyoloe_crn.yml

nms:
  name: MultiClassNMS
  nms_top_k: 1000
  keep_top_k: 300
  score_threshold: 0.01
  nms_threshold: 0.7
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `nms_top_k` | NMS 前保留的框数 | 1000 | 越大越准确，但更慢 |
| `keep_top_k` | 最终保留的框数 | 100-300 | 越大召回率越高 |
| `score_threshold` | 置信度阈值 | 0.01-0.3 | 越大越严格 |
| `nms_threshold` | IoU 阈值 | 0.5-0.7 | 越大保留越多重叠框 |

## 模型压缩与加速

### 1. TensorRT 加速

**作用**：2-3 倍推理加速

**配置方法**：
```python
from paddle.inference import Config, create_predictor

config = Config("model/model.pdmodel", "model/model.pdiparams")

# 启用 TensorRT
config.enable_tensorrt_engine(
    workspace_size=1 << 30,           # 1GB
    precision_mode=paddle.inference.PrecisionType.Float16,  # FP16
    max_batch_size=1,
    min_subgraph_size=5
)

predictor = create_predictor(config)
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `workspace_size` | TensorRT 工作空间 | 1<<30 | 越大越快，但占用更多显存 |
| `precision_mode` | 精度模式 | Float16 | FP16 更快，INT8 更快但精度损失 |
| `max_batch_size` | 最大批次大小 | 1 | 根据实际需求设置 |
| `min_subgraph_size` | 最小子图大小 | 3-10 | 越小优化越多，但可能不稳定 |

## 类别不平衡处理

### 当前数据分布

| 类别 | 数量 | 比例 |
|------|------|------|
| battery | 126 | 13.5% |
| board | 92 | 9.9% |
| fire | 712 | 76.6% |

### 解决方案

#### 1. 类别权重

**配置方法**：
```yaml
# 在损失函数中添加类别权重
PPYOLOEHead:
  loss_weight:
    class: 1.0
    iou: 2.5
    dfl: 0.5
    class_weight: [1.5, 1.5, 0.5]  # battery, board, fire
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `class_weight` | 类别权重 | [1.5, 1.5, 0.5] | 少数类权重更大 |

#### 2. Focal Loss

**作用**：关注难分类样本，缓解类别不平衡

**配置方法**：
```yaml
PPYOLOEHead:
  use_focal_loss: true
  focal_loss_alpha: 0.25
  focal_loss_gamma: 2.0
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `focal_loss_alpha` | 平衡因子 | 0.25 | 调整正负样本权重 |
| `focal_loss_gamma` | 聚焦参数 | 1.0-3.0 | 越大越关注难样本 |

#### 3. 过采样

**配置方法**：
```yaml
TrainDataset:
  !COCODataSet
  image_dir: D:/work/Marchine Dog/A_train/Image
  anno_path: mycode/data/annotations_train.json
  oversample: true
  oversample_classes: ['battery', 'board']
  oversample_ratio: 2.0
```

**超参数说明**：

| 参数 | 含义 | 推荐值 | 说明 |
|------|------|--------|------|
| `oversample` | 是否过采样 | true | 开启过采样 |
| `oversample_classes` | 过采样类别 | ['battery', 'board'] | 少数类 |
| `oversample_ratio` | 过采样倍数 | 1.5-3.0 | 越大采样越多 |

#### 4. 欠采样

**配置方法**：
```yaml
TrainDataset:
  undersample: true
  undersample_classes: ['fire']
  undersample_ratio: 0.5
```
