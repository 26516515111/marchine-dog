# 提交说明

## 一、提交包结构

将以下文件打包成 `.zip` 后上传，目录结构必须如下：

```
submission.zip
├── predict.py                                ← 推理脚本（必须）
├── model/                                    ← 模型文件（必须，总大小 ≤ 200MB）
│   ├── infer_cfg.yml                         ← 推理配置文件
│   ├── model.pdmodel                         ← 模型结构
│   └── model.pdiparams                       ← 模型权重
└── PaddleDetection/                          ← 官方部署工具（使用时必须携带）
    └── deploy/
        └── python/
            ├── preprocess.py
            ├── utils.py
            └── keypoint_preprocess.py
```

> 如果你的 `predict.py` **不使用** PaddleDetection（自己实现预处理），可以不包含该目录。

---

## 二、评测流程

评测系统会执行以下命令：

```bash
python predict.py data.txt result.json
```

- `data.txt` — 测试图片路径列表，每行一条，如 `test/Image/frame_00000.jpg`
- `result.json` — **你的脚本必须生成此文件**

评测指标：
- **F1 Score**（3 类均值，IoU 阈值 0.5）
- **FPS = 2026 / 推理耗时(s)**，FPS < 20 时得分为 0

---

## 三、result.json 格式

```json
{
  "result": [
    {
      "image_id":    "frame_00000",
      "type":        3,
      "x":           120.5,
      "y":           45.0,
      "width":       200.0,
      "height":      180.0,
      "segmentation": []
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `image_id` | string | 图片文件名（不含扩展名），如 `"frame_00000"` |
| `type` | int | 类别编号（**1-indexed**），见下表 |
| `x`, `y` | float | 检测框左上角坐标 |
| `width`, `height` | float | 检测框宽高 |
| `segmentation` | list | 留空 `[]` 即可 |

## 五、模型导出参考（PaddleDetection）

```bash
python tools/export_model.py \
    -c configs/ppyoloe/ppyoloe_crn_s_300e_coco.yml \
    --output_dir=./output_inference \
    -o weights=best_model.pdparams
```

导出后将 `output_inference/` 下的三个文件放入 `model/` 即可。

## 六、常见失败原因

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| `required file missing: predict.py` | zip 内没有 `predict.py` | 检查打包是否包含该文件 |
| `required file missing: model/` | zip 内没有 `model/` 目录 | 检查目录名拼写 |
| `model/ directory is empty` | `model/` 内无文件 | 放入三个模型文件 |
| `model/ size exceeds 200MB` | 模型超限 | 压缩或换轻量模型 |
| `predict.py exited with non-zero code` | 脚本报错 | 本地先运行：`python predict.py data.txt result.json` |
| `predict.py did not produce result.json` | 未生成输出 | 确认写入路径为 `sys.argv[2]` |
| `result.json missing "result" key` | JSON 格式错误 | 顶层必须有 `result` 字段 |
| `result.json item missing keys` | 缺少必要字段 | 检查是否含全部 6 个字段 |
| score = 0（FPS < 20） | 推理太慢 | 使用 GPU 加速，或开启 TensorRT |
